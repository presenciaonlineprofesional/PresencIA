## El problema

Una pyme o autónomo necesita web, redes sociales y SEO para tener presencia online — pero contratar tres proveedores distintos sale caro y descoordinado. PresencIA nace como una propuesta única: diseño, contenido y posicionamiento bajo una misma estrategia.

Este repositorio es el sitio web de mi propia marca de servicios digitales freelance.

<br>

## Stack técnico

| Capa | Tecnología | Por qué |
|---|---|---|
| Framework | React + Vite | build rápido, HMR instantáneo en desarrollo |
| Estilos | Tailwind CSS v2 | diseño consistente sin CSS a medida repetido |
| Tipografía | Poppins | look moderno y limpio, buena legibilidad en móvil |
| Despliegue | GitHub Pages | hosting gratuito, integrado con el flujo de Git |

## Características principales

- **Diseño responsive** — probado en móvil, tablet y escritorio con el mismo componente base.
- **Secciones modulares** — Hero, Servicios (3 tarjetas: Diseño Web, Redes Sociales, SEO), Por qué elegirnos, Contacto.
- **CTA directo a WhatsApp** — en lugar de un formulario de contacto tradicional, cada botón de "Solicitar presupuesto" abre WhatsApp con un mensaje pre-cargado, reduciendo la fricción de conversión.
- **Rendimiento** — build optimizado con Vite, sin librerías pesadas innecesarias.

## Cómo correrlo localmente

```bash
git clone https://github.com/presenciaonlineprofesional/PresencIA.git
cd PresencIA
npm install
npm run dev
```

<br>

## Despliegue

El sitio se despliega automáticamente en GitHub Pages desde la rama de producción:

```bash
npm run build
npm run deploy
```
